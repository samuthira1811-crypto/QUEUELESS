# Queue Less – Smart Clinic Appointment & Queue Management System

## About the Project

Queue Less is a web-based clinic appointment and queue management system designed to reduce patient waiting time. Patients can book appointments online, receive a token number, and track their live queue status and estimated waiting time.

Administrators can manage appointments, update patient status, and send email notifications.

## Features

- Online patient appointment booking
- Automatic token number generation
- Live queue status tracking
- Estimated waiting time calculation
- Secure admin login and logout
- Admin dashboard
- Appointment status management
- Email notifications
- MongoDB database integration
- Responsive user interface

## How It Works

1. Patients enter their details and book an appointment.
2. The system generates a unique token number.
3. Patients receive booking confirmation through email.
4. Patients can track their queue status and estimated waiting time.
5. Admin logs in to manage patient appointments.
6. Admin updates appointment status.
7. Patients receive email notifications when their appointment status changes.
